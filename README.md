# 曹将｜欢迎来到我的作品地图

一页式中文个人介绍网站。西瓜老师作为视觉主角，带访客依次认识：

- 《高效学习：曹将的公开课》
- 《PPT炼成记》
- 知识星球「AI新手村」
- 微信公众号「曹将」
- 小红书「曹将」
- 独立作品「回声日记」

## 页面体验

- 桌面端为不对称手绘舞台，五个节点围绕人物展开。
- 点击节点后，人物位置、进度条与介绍内容同步切换。
- 手机端改为横向选择节点和纵向阅读内容。
- 支持键盘焦点、触摸操作与减少动态效果偏好。

## 本地运行

```bash
npm install
npm run dev
```

## 检查

```bash
npx tsc --noEmit
npm run lint
npm test
```
